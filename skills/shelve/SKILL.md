# Shelve

Run inside the track's worktree. `ROOT=$(dirname "$(git rev-parse --path-format=absolute --git-common-dir)")`, `WT=$(git rev-parse --show-toplevel)`, `BR=$(git branch --show-current)`. If `WT` = `ROOT`, stop: this is the main checkout, nothing to shelve.

1. **Nothing is lost first.** `cd "$WT"` (the excludes and `.` are relative to the cwd). `git add -A -- . ':(exclude).worktree-bootstrapped' ':(exclude).worktree-bootstrap.log' ':(exclude).forge-brief.md'`, then `git diff --cached --quiet || git commit -qm "wip: shelved"` (commit only if something got staged); if the commit fails, stop and say why. `git push -q -u origin "$BR"` (so the branch survives the worktree); if push fails, stop and say so. Every check below runs before anything irreversible (the issue, the PR close, the removal); when any check stops you, clean up nothing.
2. **The worktree must be safe to lose.** Delete the disposable scratch: `rm -f -- .worktree-bootstrapped .worktree-bootstrap.log .forge-brief.md`. Then `git status --porcelain` must print nothing, else stop and say what is left. Then list ignored files: `git status --porcelain --ignored | grep '^!!'`. Regenerable dependency/build output (`node_modules`, `dist`, `build`, `.venv`, `__pycache__`, `.next`, `target` and the like) is fine to lose. Anything else (`.env`, local config, a local database, the gitignored `.claude/dev-loop.md` copy) is not committed and `worktree remove` would delete it: stop, name the files, and wait for the person to say to proceed (they can copy them out first). Do not guess past this.
3. **Where it stopped**, from the artifacts: design = `git diff --name-only origin/main...HEAD -- docs/decisions`, plan likewise for `docs/plans`; PR = `gh pr list --head "$BR" --state open --json number,url,body,isDraft`; tasks done = count of `- [x]` vs `- [ ]` in the PR body; the open question = the last thing an agent asked or the Deviations line that stopped it, in one sentence (read the design file's Deviations and the tab you are in). If none of that says why, ask the person once for a one-line reason; if no answer comes (the panel may have launched you with nobody at the keyboard), write `no reason recorded`.
4. **The issue.** Linked issue = the first `#n` in the PR body or design file that is an open issue: `gh issue view n --json url,state -q 'select(.state=="OPEN") | .url'` must print a URL containing `/issues/` (it also resolves PR numbers). First, in every case: `gh label create shelved --force --color 7057ff --description 'A branch holds this work' >/dev/null 2>&1`. Always open the shelf issue, so its **body** carries the `Branch:` line the panel's `branchFor` and the backlog's shelved strip read (they never read comments): `url=$(gh issue create --title 'Shelved: <track slug>' --label shelved --body-file - <<'EOF' … EOF)` — `gh issue create` prints the issue URL — and `n=${url##*/}`. If `gh issue create` fails or `url` is empty, stop here: close no PR and remove nothing. If a linked issue exists, add `Continues #<linked>.` as the body's last line, then `gh issue comment <linked> --body "Shelved; resume with /forge:start #$n."` (do not label the linked issue). Body (quoted `<<'EOF'` heredoc; `<Stage>` = Review if the PR is open and not draft, Build if a PR exists, Plan if a plan exists, Design if only a design, else Idea; date from `date +%F`):
   ```
   Shelved from track `<slug>` at <Stage> (<done>/<total> tasks) on <YYYY-MM-DD>.
   Branch: `<BR>` (pushed). Design: `<path or none>`. Plan: `<path or none>`. PR: <url or none> (closed, not merged).
   Stopped because: <one sentence>.
   Resume with `/forge:start #<n>`.
   ```
5. **Close the PR unmerged**, only after step 4 succeeded, if open: `gh pr close <number> --comment "Shelved; see #<issue>."`
6. **Remove the worktree, keep the branch**, only after step 4 succeeded. In the Herdr desktop app (`$HC_TERMINAL_ID` set): the space you are in is this worktree's; `cd "$ROOT"` first, then `git -C "$ROOT" worktree remove "$WT"` (never `--force`; if it refuses, say why and stop — steps 1 and 2 should have made it clean). On a connected machine without a Herdr window (`$HC_TERMINAL_ID` set but `herdr-app status >/dev/null 2>&1` fails), skip the close: give step 7's line, then tell the person to close this space from their Herdr window. Otherwise run `herdr-app do space.close --id "$(herdr-app ls | jq -r --arg t "$HC_TERMINAL_ID" --arg wt "$WT" '.spaces[] | select(.folder == $wt and any(.tabs[].terminals[]; .terminal == $t)) | .id')" --confirmed true` as your **last** command (it ends this terminal); if it prints nothing (you are in a space that is not this worktree's), skip the close and say so. Verified 2026-11-02: `hc ls --json` terminals carry no space field; `herdr-app ls` is JSON whose `spaces[].tabs[].terminals[].terminal` is the address, and that jq prints exactly one id. In herdr (`HERDR_ENV=1`): `cd "$ROOT" && git worktree remove "$WT"`, then tell the person to close this workspace (`herdr workspace close <id>`; the id is not reliably readable from inside the pane — not verified here). Plain: `cd "$ROOT" && git worktree remove "$WT"`.
7. Say, in one line before step 6's final command: issue URL, "branch kept", "worktree removed". Never `git branch -d`, never `-D`: the branch is the shelf.
